### **Smart 3D Elderly Care Community IoT System (S3ECCIS) User Interface design**  

#### **structure:**  

the UI of S3ECCIS is divide to 4 parts 

1: dashboard 
       provide data view of project ,include energy, health , environment, device and product
       
       product is the manufacture type/sn of the special device. it define the data
       model of the device.

2: warn
      provide the warn & advice base on the data collect from the device.
      include warn, energy save, ticket

3: policy
      define the policy of devices, to create warn ,and handle warns.


4: about
     introduction, documents and api of S3ECCIS.
